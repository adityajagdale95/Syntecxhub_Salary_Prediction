# Salary Prediction Using Machine Learning

## Project Overview

This project predicts employee salaries based on:

* Experience
* Test Score
* Interview Score

A Linear Regression model was used to train and predict salary values.

## Technologies Used

* Python
* Pandas
* Scikit-Learn
* Joblib

## Steps Performed

1. Data Loading
2. Data Exploration
3. Feature Selection
4. Train-Test Split
5. Linear Regression Training
6. Model Evaluation
7. Model Saving

## Results

### Multiple Feature Model

* RMSE: 1141.62
* R² Score: 0.9901

### Single Feature Model

* R² Score: 0.9825

## Conclusion

The Multiple Feature Model performed better than the Single Feature Model and was selected as the final model.
